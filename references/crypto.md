# 加密货币投资分析 Prompt（Crypto 适配版）

> 面向**代币 / 币种**（BTC / ETH / SOL / 主流币 / Alt）的机构级分析框架。多角色对冲基金模拟，数据必须真实抓取（CoinGecko / 链上 / 衍生品 / 社媒）。以下为原始 Prompt 原文。

```
总体指令 (Overall Mandate)

本次模拟旨在复刻一家顶级加密基金（Crypto Quant Fund）的投研决策流程。所有角色的分析都必须数据驱动 (Data-Driven)，关键论点需有数据或事实支撑。报告应体现专业性、深度和批判性思维。最终目标是为代币 [代币代码/名称] 制定一份机构级别的交易策略备忘录 (Investment Memo)。

---

第一部分：分析师团队情报输入 (Analyst Intelligence Input)

1. 通证与协议基本面报告 (Tokenomics & Protocol Fundamentals)

角色: 你是 Delphi Digital 级别的资深加密研究员，擅长挖掘长期价值与代币经济。

任务: 对 [代币代码/名称] 进行穿透式基本面分析。

报告内容应包括:

● 通证经济 (Tokenomics):
  ○ 供给与通胀: Max Supply / 当前流通量 / 年化通胀率 / 销毁机制 / 质押与解锁（vesting cliff & linear）。
  ○ 价值捕获: 代币用途（费用/治理/质押/结算）、协议收入分配、费用捕获与实际收益 (real yield)。
  ○ 估值: 市值 (Market Cap) / 完全稀释估值 (FDV) / Mcap-FDV 溢价 / 协议收入倍数 (P/S 类比) / NVT 比率（若适用）。

● 协议基本面 (Protocol Fundamentals, 如适用):
  ○ 网络活动: 活跃地址 / 日交易量 / Gas 或协议费用 / TVL（DeFi）/ 生态应用与开发者规模。
  ○ 护城河与竞争: 与同类（同类 L1 / 稳定币 / DeFi / 公链）对比，网络效应、资金规模、流动性深度、社区与开发者生态。
  ○ 安全与治理: 审计记录 / 历史攻击 / 治理中心化度 / 创始人持仓与关键人风险。

● 增长驱动与风险矩阵 (Growth Drivers vs. Risk Matrix):
  ○ 催化剂: 主网升级 / 代币经济优化 / 上架 / 合作 / 生态扩张（量化预期）。
  ○ 核心风险: 解锁抛压 / 监管 / 竞争 / 流动性质押风险 / 安全事件 / 叙事退潮（明确排序）。

---

2. 链上数据与资金面报告 (On-chain & Derivative Flow)

角色: 你是链上数据分析师（Nansen / Glassnode 级别），擅长筹码与资金动向。

任务: 量化资金与筹码的实时动态。

报告内容应包括:

● 链上结构: 持币集中度（鲸鱼）/ 交易所净流入流出 / 长期持有者 (LTH) vs 短期持有者（筹码分布）。
● 衍生品: 资金费率 (Funding Rate) / 未平仓量 (OI) 变化 / 多空比 / 爆仓数据。
● 资金流: 稳定币铸造 / 交易所净流入 / ETF 净流入（若适用）/ Mcap-FDV 缺口。
● 供需: 通胀 vs 销毁，解锁日历（未来抛压时间与规模）。

---

3. 新闻、宏观与监管报告 (News, Macro & Regulatory)

角色: 你是 CoinDesk 级别的情报分析师，对市场信息高度敏感。

任务: 解读影响 [代币代码/名称] 的外部环境。

报告内容应包括:

● 监管: 美国 SEC / CFTC / 全球监管动向、稳定性、ETF 审批与机构入场。
● 宏观: 美联储 / 利率 / CPI / 美元 / 风险偏好（加密与美股风险资产联动）。
● 事件驱动: 主网升级 / 硬分叉 / 代币解锁 / 上架 / 大额合作 / 重要人物或机构动向。

---

4. 市场情绪与资金流报告 (Sentiment & Fund Flow)

角色: 你是加密情绪分析专家（量化 Sentix 思路）。

任务: 量化市场参与者对 [代币代码/名称] 的真实态度。

报告内容应包括:

● 情绪指标: 恐惧贪婪指数 (Fear & Greed) / 社媒声量与情绪倾向 / 币安广场与社区热度。
● 机构资金: ETF / 基金流入流出、稳定币流入、机构持仓（若适用）。
● 分布: 空头 / 多头比例、期权情绪 (若可获取)。

---

5. 技术面报告 (Technical Market Report)

角色: 你是特许市场技术分析师 (CMT)，精通加密图表。

任务: 识别多空力量对比。

报告内容应包括:

● 多周期趋势: 周线 / 日线 / 4 小时 / 1 小时主要趋势。
● 相对强弱: 与 BTC 汇率（如 [代币]/BTC）、BTC.D（市值占比）、ALT/BTC 强弱。
● 关键价位与量能: 周期高低点 / 斐波那契 / 成交密集区 (Volume Profile)。
● 指标: RSI / MACD / 布林带；ATR(14) 用于动态止损；资金费率与 OI 背离（价格 vs 持仓）。

---

第二部分：投研团队激辩 (Investment Committee Debate)

1. 看涨论点 (The Bull Case)
整合正面信息构建买入逻辑，并要求回应/弱化核心风险（如解锁抛压、监管、叙事退潮）。
论证结构: "我们认为应买入 [代币]，主要基于其 [最强的通证经济/协议优势]，得到 [最有利的链上/技术信号] 确认。尽管市场担心 [一个核心风险]，但我们认为 [一个关键正面因素] 足以抵消，因为 [具体原因]。"

2. 看跌论点 (The Bear Case)
整合负面信息构建规避/做空逻辑，挑战多头核心优势。
论证结构: "我们建议规避 [代币]，核心风险在于 [最大缺陷：如通胀/解锁/监管/叙事退潮]，在 [不利信号] 中有所体现。虽然多头强调 [一个优势]，但我们认为该优势脆弱或已被高估，因为 [具体原因]。"

---

第三部分：交易主管执行计划 (Head Trader's Execution Plan)

角色: 经验丰富的加密交易主管，负责将策略转化为行动。

计划内容:

● 决策权衡: 说明 Bull / Bear 在当前市场环境下谁更有说服力及原因。
● 核心论点: 一句话概括核心驱动力。
● 具体动作: 买入 (LONG) / 卖出 (CLOSE LONG) / 做空 (SHORT) / 回补 (COVER SHORT) / 观望 (STAY ASIDE)。
● 仓位管理: 信念度（高/中/低）+ 占组合百分比（如 1% 试探、3% 标准、5%+ 核心）。
● 进出场策略:
  ○ 入场区: 具体价格区间而非单点。
  ○ 止损: 明确必须执行的止损价（可参考 2×ATR(14)）。
  ○ 止盈: TP1 / TP2 至少两档。
● 附加提示: 若使用合约，注明资金费率与爆仓风险。

---

第四部分：首席投资官最终审批 (CIO's Final Approval)

角色: 首席投资官 (CIO)，对整个组合风险收益负责。

评估备忘录:

● 风险/回报比: (TP1 - Entry) / (Entry - SL) 是否 > 2:1？是否具吸引力？
● 压力测试: "如果发生 [最可能负面事件：如监管利空 / 解锁抛压 / 黑天鹅]，止损是否有效？最大亏损是否可接受？"
● 最终决定与指令:
  ○ [ ] 交易批准 (TRADE APPROVED)
  ○ [ ] 交易驳回 (TRADE REJECTED)
  ○ 驳回理由: "驳回，因为 [风险回报比不具吸引力 / 核心逻辑存在漏洞 / 市场时机不佳]。"
```

## 使用说明

- 用真实数据替换 `[代币代码/名称]`；数据源用 `web_search` / `web_extract` / `browser_exec`（CoinGecko / 链上浏览器 / 交易所 API / 新闻）。
- 加密特有指标优先：市值 / FDV / 解锁日历 / 资金费率 / OI / 稳定币与 ETF 流向 / 恐惧贪婪 / BTC 相对强弱。
- 所有量化论断需可回溯，禁止编造数字；开头保留免责声明（不构成投资建议，加密风险极高）。
