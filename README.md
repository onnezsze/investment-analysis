# Investment Analysis 技能

用一套对冲基金投研级别的**多角色分析框架**，对某只股票产出**机构级投资备忘录 (Investment Memo)**。

## 模块

- **基本面全流程**（`references/fundamentals.md`）：分析师团队情报 4 份报告 → 投研团队多空辩论 → 交易主管执行计划 → 首席投资官审批。
- **技术面深度分析**（`references/technical.md`）：风险前置免责声明 → 量化数据仪表盘 → 多维时间框架共振 → 相对强度与波动率 → 交易剧本与风险矩阵 → 最终建议。

## 来源

## 使用注意

- 数据一律来自真实抓取来源，禁止编造数字。
- 报告开头必须保留免责声明，明确"不构成投资建议"。
- 本仓库为私有托管备份，技能实际由 Hermes Agent 在 `~/.hermes/skills/finance/investment-analysis/` 加载使用。
